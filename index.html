/ Documentation & Instructions

How to Add Your Own Works & Update the Site

A beginner-friendly guide tailored specifically for you so you can easily add your future Photoshop exports, update project cards, and maintain your website with confidence.

01 How to Export from Photoshop with Ideal Settings

When you finish a poster in Adobe Photoshop, follow these export steps for optimal web speed and crisp quality:

  • Go to File > Export > Export As... (or Save for Web (Legacy)).
  • Format: Choose JPG (or PNG if you need transparent backgrounds).
  • Quality: Set between 80% and 85% (Quality 7–8). This provides crystal-clear visuals while keeping file size under 300 KB.
  • Color Space: Check "Convert to sRGB" so colors match accurately on all mobile screens and web browsers.
  • Recommended Dimensions: Width around 1200px to 1600px for posters.
02 Folder Placement & Naming Conventions

Always name your files using lowercase letters and hyphens (avoid spaces or special symbols like # or @):

images/graphic-design/
  ├── esports-nne-champions.jpg
  ├── tournament-champions.jpg
  └── client-social-banner.jpg

Place your newly exported image directly inside the images/graphic-design/ folder.

03 Adding a New Project Card in HTML (Working Example)

Open index.html in VS Code. Find the <div class="gallery-grid" id="galleryGrid"> section, and paste this card block:

<!-- Copy & Paste this snippet inside gallery-grid -->
<article class="gallery-card tilt-card" data-category="esports">
  <div class="card-media">
    <img src="images/graphic-design/esports-nne-champions.jpg" alt="PUBG Championship Roster" loading="lazy">
    <div class="card-overlay">
      <span class="view-pill">Click to Enlarge 🔍</span>
    </div>
  </div>
  <div class="card-meta">
    <span class="meta-tag">Esports & Gaming</span>
    <h3 class="card-title">PUBG Championship Roster</h3>
    <p class="card-tools"><strong>Tool:</strong> Adobe Photoshop</p>
    <p class="card-desc">Custom team roster poster with dramatic rim lighting and custom typography.</p>
  </div>
</article>

Tip: For data-category, use esports, posters, branding, or social. You can also use multiple separated by spaces (e.g. data-category="posters esports")!

04 How to Run & Test Locally in VS Code
  1. Open Visual Studio Code.
  2. Go to File > Open Folder... and select your MyPortfolio folder.
  3. Install the "Live Server" extension (by Ritwick Dey) from the Extensions tab (Ctrl+Shift+X).
  4. Right-click index.html and select "Open with Live Server".
  5. Your browser will launch at http://127.0.0.1:5500 with live auto-reloading whenever you save changes!
05 How to Publish Online for Free (GitHub Pages & Netlify)

Option A: GitHub Pages (Recommended for developers)

  1. Create a free account at GitHub.com.
  2. Create a new public repository named portfolio (or sulav-dhital.github.io).
  3. Upload all files from your MyPortfolio folder (make sure index.html is in the root).
  4. Go to Settings > Pages.
  5. Under Branch, select main and folder / (root), then click Save.
  6. Within 1 minute, your portfolio will be live at: https://<your-username>.github.io/portfolio/!

Option B: Netlify (Drag & Drop in 30 seconds)

  1. Sign up for free at Netlify.com.
  2. Go to the Sites tab.
  3. Simply drag and drop your whole MyPortfolio folder into the browser window.
  4. Netlify will instantly give you a live free URL (e.g. sulav-dhital.netlify.app).
